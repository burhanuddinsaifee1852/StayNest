# StayNest

StayNest is a student accommodation and living ecosystem for students, PG owners and hostel owners.

## Main Goal

Help students find suitable accommodation and help property owners manage their rooms, tenants, rent and vacancies.

## Technology Stack

### Frontend
- React
- TypeScript

### Backend
- Java 17
- Spring Boot

### Planned Database
- PostgreSQL

## Future Features

- PG and Hostel Search
- Property Listings
- Room and Bed Management
- Tenant Management
- Rent Management
- Booking
- Reviews
- Maps
- Roommate Matching
- Tiffin Services
- Laundry Services
- Payments
- AI Recommendations
